[![Live Site](https://img.shields.io/badge/Live_Portfolio-1D4ED8?style=for-the-badge&logo=githubpages&logoColor=white)](https://vishalchoudhary07.github.io/vishal-portfolio/)
[![Deploy Status](https://img.shields.io/github/actions/workflow/status/vishalchoudhary07/vishal-portfolio/deploy.yml?style=for-the-badge&label=Deploy)](https://github.com/vishalchoudhary07/vishal-portfolio/actions/workflows/deploy.yml)

A static-exported developer portfolio built with **Next.js (App Router)**, **TypeScript**, and **GSAP**. Designed around a **Swiss Engineering** light canvas (`#F4F3EE`) paired with high-contrast dark interactive system modules (`#111318`).

## Highlights

* **Hybrid Swiss Engineering UI:** Warm architectural paper canvas, drafting grid overlay, and Cobalt (`#1D4ED8`) / Signal Orange (`#FF4D2D`) accents framing dark hardware-style interactive panels.
* **Pinned Horizontal Work Showcase:** Scroll-driven project track powered by GSAP `ScrollTrigger` featuring live interactive previews—a packet-filtering firewall monitor, an AI/PostGIS query inspector, and a sorting algorithm sandbox.
* **Interactive Contact Shell:** Built-in terminal supporting `whoami`, `status`, `ping`, `copy`, `send <message>`, `Tab` autocomplete, and command history (`↑` / `↓`).
* **Custom Motion & Navigation:** Lenis smooth scrolling synchronized with GSAP, text-scramble hero typography, scroll-aware HUD navigation, magnetic buttons, and a pointer-reactive custom cursor.
